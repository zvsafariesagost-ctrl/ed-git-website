# Farmacia Zinval

## Project description

Farmacia Zinval is a fictional pharmacy website created as part of a web development assignment. Its purpose is to present the pharmacy.

## Technologies used

- HTML5
- CSS3

## How to open the website

1. Download or clone this repository.
2. Open the project folder.
3. Double-click on `index.html`.
4. The website will open in your default web browser
